# Contributing to OpenATV / Enigma2 research

Only **OpenATV/Enigma2** GTX-related observations and source patches belong here; CoreELEC findings are documented separately. Please include exact device model, board revision if known, external boot medium, image/kernel ABI, module names, observation date, logs, test conditions and confidence label (operator-log, reported, inferred, untested).

Keep proprietary binary modules, firmware, unauthorized copyrighted materials and internal dumps out of the project. Strip credentials, serial numbers, private identifiers and sensitive addresses from logs. Never recommend modifying internal Mars flash as a routine reproduction step.

Source patches should document provenance, applicable driver/kernel versions, expected behavior and measurable pass/fail results. Project-wide licensing awaits maintainer selection.
